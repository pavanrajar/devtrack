# Security Policy

## Reporting a vulnerability

Please report suspected security vulnerabilities privately using GitHub's **Report a vulnerability** option under the repository's Security tab, if enabled. If private vulnerability reporting is unavailable, contact a repository maintainer through a private GitHub channel.

Do not include credentials, personal data, or exploit details in a public issue. Provide the affected component, impact, and steps to reproduce using a local or otherwise authorized environment.

## Supported versions

Only the current default branch is actively maintained until release versions are published.

## Handling secrets

Never commit `.env` files, production credentials, or real user data. Rotate any credential that may have been exposed.
