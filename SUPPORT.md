# Support

- For reproducible defects, use the **Bug report** issue template.
- For proposed functionality, use the **Feature request** issue template.
- For setup questions, include the operating system, Node.js version, commands run, and sanitized error output.
- Do not post passwords, access tokens, database connection strings, or personal data.
- For suspected security issues, follow [SECURITY.md](./SECURITY.md) instead of opening a public issue.

DevTrack does not currently have a hosted demo or a guaranteed response-time commitment.
